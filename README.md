## 1. الملخص التنفيذي | Executive Summary

تُمثل الرعاية الصحية المعرفية لكبار السن أحد أكبر التحديات الطبية والاجتماعية المعاصرة، نتيجة تأخر رصد علامات التراجع المعرفي المبكر، والآثار الجانبية التراكمية للأدوية متعددة الوصفات (**Anticholinergic Burden**)، إضافة إلى الضغط النفسي الواقع على كاهل الأسرة ومقدمي الرعاية.

يقدم **WANIS-AI (ونيس)** حلاً متكاملاً ومسؤولاً يرتكز على خمس ركائز هندسية وسريرية:
1. **الواجهة الطبيعية الصوتية الفائقة البساطة**: التفاعل الصوتي الدافئ بمرونة لغوية تدعم اللهجات العربية والخليجية دون أي تعقيد تقني أو حاجة لخبرة مسبقة.
2. **الذكاء السريري القائم على الأدلة (ACB 2.0)**: حساب تتبعي فوري لمؤشر **Anticholinergic Cognitive Burden** لتفادي حالات التشوش الذهني الحاد (Delirium) والوقاية من السقوط ومراجعة الأدوية ذات الخطورة العالية.
3. **التنبيه الاستباقي المؤتمت (4-Color Triage)**: رصد التغيرات الدقيقة عن خط الأساس الصحي (`GREEN` ➔ `YELLOW` ➔ `ORANGE` ➔ `RED`) وإطلاق إشعارات متعددة القنوات مع نغمات صوتية توافقية مركبة عبر Web Audio API.
4. **بطاقة الطوارئ الرقمية والالتقاط البيومتري الحقيقي**: دعم تشغيل الكاميرا الحقيقية للجهاز أو المحاكاة المعيارية للتحقق الفوري من هوية كبير السن عند الطوارئ بست لغات عالمية، وتسهيل التدخل الإسعافي.
5. **رفيق الحج والعمرة (رفقة)**: نظام سلامة ميداني متكامل يشمل وضع التائه، عداد أشواط الطواف والسعي، مستشعر اتزان الحركة ثلاثي المحاور (IMU)، ومحرك طقس مباشر للمشاعر المقدسة مع 7 بطاقات إرشاد صحي وشرعي تكيفية.
6. **الخصوصية الصفرية ومصفوفة الموافقات الرباعية**: معمارية أمان متوافقة مع **نظام حماية البيانات الشخصية السعودي (PDPL)** ومعايير **HIPAA**، تضمن الملكية الكاملة لكبير السن لبياناته وحفظ كرامته.

## 3. المحاور والوحدات الوظيفية | Core Modules

### 3.1 فحص الاطمئنان الصوتي الذكي (Daily Voice Check-in)
* **معالجة الصوت الحواري الطبيعي**: استقبال الصوت أو النصوص وتحليلها بمرونة تراعي اللهجات العربية والخليجية ومفردات كبار السن.
* **الاستخلاص المعرفي والفسيولوجي المتعدد الأبعاد**:
  * **جودة ومدة النوم**: استخراج ساعات النوم وأنماط التقطع الليلي ومطابقتها مع خط الأساس.
  * **مؤشر المزاج والنشاط**: تقييم نبرة الصوت والمفردات المعبرة عن الراحة، النشاط، أو الإجهاد.
  * **مستوى التواصل الاجتماعي والشهية**: رصد التفاعل الأسري وتناول الوجبات وشرب السوائل.
* **تمارين تنشيط الذاكرة المعرفية**: أسئلة تفاعلية دافئة لتنشيط الذاكرة واسترجاع التجارب الإيجابية بأسلوب غير اختباري يحفظ كرامة كبير السن.

---

### 3.2 بروتوكول إشعارات دائرة الرعاية (Care Circle Alerts & Chimes)
* **رصد التحول اللحظي**: انطلاق استجابة فورية مؤتمتة عند تغير الحالة السريرية من خط الأساس (`GREEN` ➔ `YELLOW` أو `ORANGE` أو `RED`).
* **إشعارات متعددة القنوات والوسائط**:
  * **نغمات صوتية توافقية**: توليد إشارات صوتية عبر **Web Audio API** (`playTriageAlertChime`) بنغمات مهدئة للحالات العادية، وتنبيهات تصاعدية للحالات الطارئة.
  * **إشعارات المتصفح الفورية**: بث تنبيهات **Web Push Notifications** لإحاطة أفراد العائلة فوراً.
  * **بطاقة التنبيه التفاعلية (`CareCircleTriageToast`)**:
    * مؤشر زمني حي يوضح عدد الثواني المنقضية منذ انطلاق التنبيه (`Live Timer Badge`).
    * شريط تقدم بصري يوضح مسار التدخل النشط مع إجراءات الاتصال والاطمئنان بلمسة واحدة.
    * وميض نبضي متدرج للحالات الحرجة (`RED Alert Pulse Animation`).

---

### 3.3 ملخص العافية اليومي التجميعي (Daily Wellness Summary)
* **واجهة ترحيبية فور تسجيل الدخول**: تُعرض لأفراد العائلة ومقدمي الرعاية عند فتح بوابة الأسرة.
* **تجميع موحد وشامل**: دمج نتائج الفحص الصوتي الصباحي، نسبة الالتزام بالأدوية، ومؤشر ACB في بطاقة موحدة سهلة القراءة.
* **توصيات إرشادية فورية**: نصائح مبنية على بيانات اليوم (مثل زيادة الترطيب، أو جدولة استراحة، أو التواصل الهاتفي مع الوالدة).

---

### 3.4 محرك العبء المعرفي للأدوية (ACB 2.0 Risk Engine & Medication Center)
* **الوقاية من التدهور المعرفي (Anticholinergic Cognitive Burden)**:
  * حساب التراكم الكوليني للأدوية اليومية وفق المعايير السريرية العالمية (Boustani / CRISTAL Scales).
  * تنبيه الأطباء والعائلة عند تجاوز المؤشر للحد الحرج ($\text{ACB} \ge 3$).
  * إتاحة بدائل علاجية مقترحة لتسهيل نقاش الطبيب مع المريض (Deprescribing Guidance).
* **مركز التذكير بالأدوية وإدارة الإشعارات (`MedicationReminderCenterModal`)**:
  * واجهة بصرية مزودة بصور واضحة للأقراص والجرعات لتفادي الالتباس.
  * إطلاق التنبيهات الفورية الصوتية مع قراءة الجرعة صوتياً والتأكيد بلمسة واحدة.
  * مؤشر المزامنة السحابية وسجل التاريخ الكامل للالتزام لمدة 30 و 90 يوماً.

---

### 3.5 بطاقة الطوارئ الرقمية والالتقاط البيومتري (Digital ID & Bio-Camera)
* **حاوية الصورة الشخصية والتحقق الميداني**:
  * عرض الصورة الشخصية لكبير السن مع شارة التحقق البيومتري المعتمدة للمسعفين، فصيلة الدم، الحساسيات الدوائية، ورقم الهوية/الإقامة.
* **كاميرا الالتقاط البيومتري الطبي المباشر (`CameraCaptureModal`)**:
  * دعم كامل لتشغيل كاميرا الجهاز الحقيقية عبر `navigator.mediaDevices.getUserMedia` مع نمط محاكاة عالي الدقة كبديل فوري.
  * دليل ضبط ومحاذاة الوجه البيضاوي (Facial Alignment Guide).
  * صوت الغالق البصري (Shutter Audio via Web Audio) ومؤقت ذاتي للالتقاط (3s Self Timer).
  * تسجيل فوري لعمليات التحديث في سجل المراقبة والأمان (Access Audit Logs).
* **دعم 6 لغات عالمية**:
  * عرض البيانات السريرية الحرجة بالعربية، الإنجليزية، الفرنسية، الأردية، الإندونيسية، والتركية لتسهيل إسعاف ضيوف الرحمن من مختلف الجنسيات.

---

### 3.6 موجز الطبيب السريري (Doctor Brief 2.0 & SBAR Clinical Engine)
* **تقرير موجه للعيادة يُقرأ في أقل من دقيقتين**: تلخيص المنحنيات المعرفية، استقرار النوم، والالتزام الدوائي وفق هيكل **SBAR** السريري المعتمد:
  * **S (Situation)**: سبب المراجعة والحالة الحالية ودرجة ACB.
  * **B (Background)**: التاريخ الطبي وقائمة الأدوية النشطة وخط الأساس.
  * **A (Assessment)**: تحليل التغيرات لآخر 14/30 يوماً واقتباسات حرفية من المريض.
  * **R (Recommendation)**: مقترحات سريرية لتعديل الأدوية والفحوصات المخبرية.
* **التصدير والطباعة الموثقة**: تصدير فوري بصيغة PDF عالية الدقة مع الختم الرقمي لتسهيل إدراج التقرير في الملف الطبي الإلكتروني (EMR / EHR).

---

### 3.7 رفيق الحج والعمرة ومعرض الصحة والطقس (Rufqa Pilgrim Safety, Health & Weather Carousel)
* **معرض الصحة والعافية التكيفي في الحج (`HajjHealthWellbeingCarousel`)**:
  * **محرك الطقس المباشر للمشاعر المقدسة**: متابعة حية لـ 5 مواقع مقدسة (المسجد الحرام، مخيمات منى، صعيد عرفات، مزدلفة، والمسجد النبوي) تشمل درجات الحرارة الفعلية والمحسوسة، مؤشر الأشعة فوق البنفسجية (UV Index)، نسبة الرطوبة، وسرعة الرياح، مع تحديد نوافذ المشي الآمنة وتجنب أوقات الذروة.
  * **7 بطاقات إرشاد صحي وشرعي ديناميكية**: (الشمس والحرارة، ترطيب ماء زمزم والأملاح، العناية بالقدم السكرية والمفاصل، مزامنة الأدوية مع المناسك، الرخص الشرعية والتيسير النبوي، التغذية الخفيفة والقيلولة، وتجنب التدافع).
  * **التكيف المباشر مع تقدم الحاج**: ربط فوري بين الإرشاد المعروض وعدد خطوات الحاج، أشواط الطواف المنجزة، ومستوى الترطيب المسجل.
  * **قراءة صوتية وشروح سريرية وشرعية**: استماع صوتي فوري للإرشاد عبر `speakText` مع استعراض الأساس الفسيولوجي والرخص الفقهية.
* **وضع التائه الذكي (Lost Mode)**:
  * تفعيل بث الطوارئ بلمسة واحدة مع إرسال الإحداثيات المباشرة لمطوف الحملة وأفراد الأسرة وخريطة تفاعلية للمشاعر المقدسة.
* **عداد الخطوات ومتابعة المناسك (Hajj/Umrah Step Counter)**:
  * عداد تفاعلي مخصص لكبار السن مع تحديد الأهداف اليومية (4,000 / 7,500 / 10,000 خطوة).
  * **متتبع أشواط الطواف والسعي (7 أشواط)**: توثيق إتمام كل شوط مع تهنئة صوتية واحتساب الخطوات التقديرية.
* **مختبر مستشعر الحركة IMU (3-Axis Accelerometer Lab)**:
  * قراءات التسارع اللحظية على المحاور الثلاثة ($X, Y, Z$) ومؤشر اتزان المشية (Gait Stability Index) لرصد بوادر الإرهاق أو التعثر.

```text
┌───────────┐      ┌────────────┐      ┌───────────┐     ┌───────────┐
│    ACT    │  ➔   │   SHARE    │  ➔   │ FOLLOW-UP │  ➔  │   LEARN   │
│  التدخل   │      │  المشاركة  │      │  المتابعة │     │  التعلم   │
└───────────┘      └────────────┘      └───────────┘     └───────────┘
```

1. **الملاحظة (OBSERVE)**: التقاط الإشارات الصوتية والحركية والالتزام بالأدوية.
2. **الفهم (UNDERSTAND)**: تحليل المعنى والنبرة والمؤشرات المعرفية عبر نماذج Gemini.
3. **التقييم (ASSESS)**: مطابقة الحالة مع خط الأساس وحساب مؤشرات الفرز السريري و ACB.
4. **التوصية (RECOMMEND)**: صياغة إرشادات مخصصة تناسب الحالة الصحية والظروف المحيطة.
5. **التدخل (ACT)**: إطلاق التنبيهات، تذكير الأدوية، أو تفعيل بروتوكول الطوارئ.
6. **المشاركة (SHARE)**: بث ملخصات العافية للأسرة وموجزات الطبيب وفق مصفوفة الخصوصية.
7. **المتابعة (FOLLOW-UP)**: التحقق من استجابة كبير السن والأسرة واستقرار المؤشرات.
8. **التعلم (LEARN)**: تحديث خط الأساس الشخصي لتحسين دقة الرعاية المستقبلية وتفادي الإنذارات الخاطئة.

## 8. دليل التثبيت والتشغيل | Installation & Deployment

### المتطلبات الأساسية
* بيئة تشغيل **Node.js** (الإصدار `18.x` أو أعلى / يُفضل `20.x` LTS).
* مفتاح وصول **Google Gemini API Key** من [Google AI Studio](https://aistudio.google.com/).

### خطوات التشغيل المحلي (Development)

```bash
# 1. استنساخ المستودع البرمجي
git clone https://github.com/4-u1/WANIS-AI.git
cd WANIS-AI

# 2. تثبيت الحزم البرمجية والاعتماديات
npm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# قم بإدخال مفتاح Gemini الخاص بك داخل ملف .env:
# GEMINI_API_KEY=your_gemini_api_key_here

# 4. تشغيل خادم التطوير المتكامل (Backend + Frontend)
npm run dev
```

التطبيق سيعمل مباشرة عبر المنفذ المحلي: `http://localhost:3000`

### فحص سلامة الأنماط والشيفرة (Lint & Type Check)

```bash
npm run lint
```

### بناء نسخة الإنتاج والتشغيل (Production Build & Start)

```bash
# بناء ملفات الواجهة المجمعة وتجميع خادم Express بواسطة esbuild
npm run build

# تشغيل خادم الإنتاج المحزوم
npm start
```
